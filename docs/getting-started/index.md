# Get started

New to the Agent Filesystem Interface? Read the [introduction](intro.md) first
to build the mental model, then pick a path:

<div class="grid cards" markdown>

-   :material-server: **[Build a provider](build-a-provider.md)**

    You have a data source (docs, database, object store, indexed corpus).
    Expose it as an AFI provider so any agent can `ls`, `cat`, `grep` it.

-   :material-account-cog: **[Build a client](build-a-client.md)**

    You're building an agent runtime and want to consume any AFI provider
    through a single, stable interface.

</div>

For deeper background, see [Learn](../learn/index.md). For normative
requirements, see the [Specification](../specification/index.md).
